# LCI-GCF Inference Demo

This repository provides an inference-only demo for qualitative evaluation of **LCI-GCF**, a lightweight causal class-label-guided target sound extraction model.

This repository is not a full reproduction package. Training code, full PyTorch model implementation, experimental configurations, ablation scripts, data preparation scripts, and the full evaluation pipeline are not included in this version.

## Overview

Each demo case contains one mixture audio and two target sound classes. For each target class, we provide the clean target signal and the extracted outputs generated by the proposed LCI-GCF model and baseline models.

This repository is intended for qualitative listening checks during the review period. Model architecture details are described in the paper.

## Demo Audio Samples

Each demo case may contain the following files:

| File pattern             | Description                                       |
| ------------------------ | ------------------------------------------------- |
| `mixture.wav`            | Input mixture audio                               |
| `clean_<target>.wav`     | Ground-truth target sound for the specified class |
| `LCI_GCF_<target>.wav`   | Extracted output by the proposed LCI-GCF model    |
| `SoundBeam_<target>.wav` | Extracted output by the SoundBeam baseline        |
| `ACN_<target>.wav`       | Extracted output by the ACN-TCN baseline, if available |

## Inference-only Demo

This repository only contains:

- Demo audio samples.
- A minimal `inference.py` script.
- A TorchScript inference model: `checkpoints/lci_gcf_demo.pt`.
- A class label mapping file: `labels.json`.
- Example inference commands.

The provided TorchScript model is used only for demo inference. Model architecture details are described in the paper.

The inference script reads a mono or stereo wav file, converts it to mono, resamples it to 16 kHz, adjusts it to the demo length, runs the TorchScript model, and saves the extracted wav.

## Installation

Install the minimal inference dependencies:

```bash
pip install -r requirements.txt
```

## Run Inference

From the repository root, run:

```bash
python inference.py --input examples/sample_01/mixture.wav --label Harmonica --model checkpoints/lci_gcf_demo.pt --output outputs/sample_01_harmonica.wav
```

```bash
python inference.py --input examples/sample_01/mixture.wav --label Snare_drum --model checkpoints/lci_gcf_demo.pt --output outputs/sample_01_snare_drum.wav
```

Additional demo commands:

```bash
python inference.py --input examples/sample_02/mixture.wav --label Flute --model checkpoints/lci_gcf_demo.pt --output outputs/sample_02_flute.wav
python inference.py --input examples/sample_02/mixture.wav --label Hi-hat --model checkpoints/lci_gcf_demo.pt --output outputs/sample_02_hihat.wav
python inference.py --input examples/sample_03/mixture.wav --label Keys_jangling --model checkpoints/lci_gcf_demo.pt --output outputs/sample_03_keys_jangling.wav
python inference.py --input examples/sample_03/mixture.wav --label Saxophone --model checkpoints/lci_gcf_demo.pt --output outputs/sample_03_saxophone.wav
```

The extracted audio will be saved in the `outputs/` directory. These commands are intended for qualitative listening checks only.

## Dataset Sources

The experiments described in the paper use publicly available datasets and tools, including FSDKaggle2018, TAU Urban Acoustic Scenes 2019, FSDSoundScapes metadata, and Scaper.

The original datasets are not redistributed in this repository due to dataset license restrictions. This repository does not contain data preparation scripts, complete dataset splits, training data, or full evaluation scripts.
